Exercise 1Welford's recurrences

For scores x1, …, xk let Mk = (1/k) Σ xi be the mean, SSk = Σ (xi − Mk)² the sum of squares and s²k = SSk/(k − 1) the sampling variance.

Mean (Knuth)

k·Mk = (k − 1)·Mk−1 + xk
Mk = Mk−1 + (xk − Mk−1) / k

Two identities used below

(a) Mk − Mk−1 = (xk − Mk−1) / k
(b) xk − Mk = (k − 1)(xk − Mk−1) / k = (k − 1)(Mk − Mk−1)

Sum of squares

SSk = Σi≤k xi² − k·Mk²
SSk − SSk−1 = xk² − k·Mk² + (k − 1)·Mk−1²
k·Mk² = Mk[(k − 1)·Mk−1 + xk]
⇒ xk(xk − Mk) − (k − 1)·Mk−1(Mk − Mk−1)
by (b): (k − 1)(Mk − Mk−1) = xk − Mk
SSk = SSk−1 + (xk − Mk−1)(xk − Mk)
by (b) also: SSk = SSk−1 + (k − 1)/k · (xk − Mk−1)²

Variance

s²k = SSk / (k − 1) = [SSk−1 + (k − 1)/k · (xk − Mk−1)²] / (k − 1)
s²k = (k − 2)/(k − 1) · s²k−1 + (xk − Mk−1)² / k   for k ≥ 2

Start: M1 = x1, SS1 = 0. Each new score needs O(1) work and no stored history.

Code and live check

let mean = 0, ss = 0, k = 0;

function add(x) {
  k++;
  const d = x - mean;     // x_k - M_{k-1}
  mean += d / k;          // M_k
  ss   += d * (x - mean); // SS_k
}
// sampling variance: ss / (k - 1)

Exercise 2Sampling mean and variance

Same setting as the previous homework: m hackers, each attempting n systems in sequence. Each attempt now receives a score from 0 to 10 drawn from a Binomial(10, 0.4) distribution: a score is the number of ten independent checks passed, each with probability 0.4. Each hacker's n scores are fed to the recurrences above, giving a sampling mean and a sampling variance s² (divisor n − 1). Those two numbers are then averaged over the m hackers.

Method. Scores come from a seeded 128-bit generator (sfc32) through the inverse of the Binomial(10, 0.4) distribution function. Theory: Var(x̄) = σ²/n and Var(s²) = μ4/n − σ4(n − 3)/(n(n − 1)), where μ4 is the fourth central moment of the score distribution.
