Step 3Independence, expected frequencies and χ²

      

        

          
Probability

          

            
A, B independent ⇔ P(A ∩ B) = P(A)·P(B)

            
⇔ P(B | A) = P(B),  if P(A) > 0

            
X, F independent ⇔ P(X = xi, F = yj) = P(X = xi)·P(F = yj) for all i, j

          

        

        

          
Statistics

          

            
fij = fi··f·j for all i, j

            
⇔ f(F | X = xi) = f·j for every i

            
Eij = ni··n·j / n

            
χ² = Σij (nij − Eij)² / Eij,  df = (r − 1)(c − 1)

          

        

      

      
Sample frequencies never match independence exactly, so χ² measures the gap. Under independence χ² is approximately chi-square distributed with (r − 1)(c − 1) degrees of freedom, provided all Eij ≥ 5. The p-value is P(χ²df ≥ observed value), computed from the regularized incomplete gamma function (as a logarithm, because for these data it is far below the smallest representable double).
