Exercise 1Riemann and Lebesgue integration

Both sums approximate ∫ab f(x) dx with n cells (Riemann) or n levels (Lebesgue).

Riemann sum (partition of the domain)

Δ = (b − a)/n, xi = a + (i − ½)Δ
Rn = Σi=1..n f(xi)·Δ

Midpoint rule. Cost: n evaluations of f.

Lebesgue sum (partition of the range)

yj = m + j·h, h = (T − m)/n, Ej = {x : yj ≤ f(x) < yj+1}, En = {f ≥ T}
Ln = Σj=0..n yj·μ(Ej) = ∫ φn, φn ≤ f simple

m = inf f, T = sup f (T = √n for the unbounded 1/√x). Error ≤ h(b − a). The hard part is μ(Ej).

Two ways to obtain μ(Ej)

Exact preimages. μ{f < t} is found by bisection on each monotone piece of f, about 60 evaluations per level and piece. A constant piece is read in one evaluation.

Sampled preimages. N = n² midpoint samples are sorted into the levels and counted, μ(Ej) ≈ count·(b − a)/N. The level error shrinks like 1/n and the counting error like n/N, so N = n² balances them.

Pathological functions

Dirichlet: 1 on the rationals, 0 on the irrationals. Thomae: 1/q at p/q in lowest terms, 0 on the irrationals. Every machine number is rational, so these functions cannot be sampled; the Riemann tags are chosen by their class (rational xi = i/n, or an irrational point of each cell), and the Darboux sums follow from the definitions.

Exercise 2Numerical computation of the normal CDF

Φ(x) = ∫−∞x φ(t) dt with φ(t) = e−t²/2/√(2π). By symmetry Φ(−x) = 1 − Φ(x), so it is enough to work with x ≥ 0, and Φ(x) = ½ + ∫0x φ.

Methods

Numerical integration

trapezoid: ∫0x φ ≈ h[φ(0)/2 + Σi=1..n−1 φ(ih) + φ(x)/2], error O(h²)
Simpson: (h/3)[φ(0) + 4Σodd φ(ih) + 2Σeven φ(ih) + φ(x)], error O(h⁴)

h = x/n. n + 1 evaluations of exp, so the cost grows with the accuracy asked.

Series expansion

alternating: ∫0x φ = (1/√(2π)) Σk≥0 (−1)k x2k+1 / (2k k! (2k+1))
positive terms: ∫0x φ = φ(x) · Σk≥0 x2k+1/(2k+1)!!
tk = tk−1 · x²/(2k+1), t0 = x

Positive form: S(x) = Σ x2k+1/(2k+1)!! solves S′ = 1 + xS, hence (e−x²/2S)′ = e−x²/2. No cancellation, unlike the alternating form.

Continued fraction for the tail

Q(x) = 1 − Φ(x) = φ(x) / (x + 1/(x + 2/(x + 3/(x + …)))), x > 0

Evaluated bottom-up with K = ⌈160/x⌉ levels. It converges faster as x grows and gives the tail directly, without computing 1 − Φ.

Hybrid and rational approximation

hybrid: positive series for x < 3, continued fraction for x ≥ 3
A&S 26.2.17: Q(x) ≈ φ(x)(b1t + … + b5t⁵), t = 1/(1 + 0.2316419x)

The hybrid is the proposed method. The polynomial has |error| < 7.5·10−8 at the price of one exp and about ten multiplications.

Why Φ is not elementary: Liouville’s theorem

Statement

Liouville (1835), in the form given by Rosenlicht (1972): let f and g be rational functions, g non-constant. Then ∫ f eg dx is an elementary function if and only if there is a rational function R with

f = R′ + R·g′, and then ∫ f eg dx = R eg

Application to e−x²/2

f = 1, g = −x²/2, g′ = −x ⇒ need R′ − xR = 1
R = 0 gives 0 ≠ 1
R polynomial of degree d ≥ 0: deg(R′ − xR) = d + 1 ≥ 1
R with a pole of order m ≥ 1 at a: R′ has order m + 1, xR at most m, so R′ − xR still has a pole at a

No rational R solves the equation, so ∫ e−x²/2 dx is not elementary. The total integral over ℜ is still exactly √(2π) (polar coordinates), but Φ(x) at finite x is not a finite combination of elementary functions.

The error function

erf(z) = (2/√π) ∫0z e−t² dt
Φ(x) = ½ [1 + erf(x/√2)], Q(x) = ½ erfc(x/√2)

This is an exact representation, but it works by naming the integral as a new function. A processor performs only +, −, ×, ÷ and √ exactly, so erf, like exp or sin, must still be evaluated through a series, a continued fraction or a rational approximation, and each of these has its own accuracy range. The practical difficulty is cancellation: the alternating series fails for large x and 1 − Φ(x) loses all significant digits in the tail, so one needs erfc, or the tail Q, computed directly.
